마이라이프 구성도

경제, 독서, 공부, 취미, 일기, 건강, 계획을 한 앱에서 기록하는 개인용 웹앱입니다. 지금까지 고르신 내용을 그대로 정리했습니다. 이 구성이 맞으면 이대로 구현을 시작합니다.

시스템 구성

구글 시트 방식이 느렸던 이유는 버튼을 누를 때마다 시트 전체를 읽고 썼기 때문입니다. 이 구성에서는 화면이 기기 안에서 바로 그려지고, 필요한 기록만 데이터베이스와 주고받습니다.

화면 구성

PC에서는 왼쪽 메뉴에 8개가 모두 보이고, 폰에서는 아래쪽에 홈·경제·기록·계획·더보기 5개 탭이 보입니다.

메뉴들어가는 기능
홈위쪽: 오늘의 할 일, 습관 체크, 일정, 이번 달 지출과 빠른 입력 버튼. 아래쪽: 순자산, 지출, 독서량, 공부 시간, 습관 달성률 통계
경제수입·지출 가계부, 카테고리별 월 예산, 매달 자동 등록되는 고정 지출, 자산·부채와 순자산 추이, 투자 기록과 수익률투자 평가액은 직접 입력합니다. 시세 자동 조회는 없습니다.
일기·메모하루 한 편 일기(기분 5단계, 잘한 일·아쉬운 일·감사한 일, 자유 글, 사진), 메모·아이디어 보관함
독서제목 검색으로 책 등록, 읽고 싶은·읽는 중·완독 상태, 쪽수 진도, 별점, 감상문, 인상 깊은 문장
공부과목, 강의·교재 등록과 진도율, 공부 기간, 날짜별 공부 시간(타이머 또는 직접 입력)
취미취미별 활동 일지(날짜, 시간, 메모, 사진), 영화·드라마·게임 등 감상 기록(별점, 한 줄 평)
건강체중과 목표 체중, 운동, 수면 시각, 식단과 물
계획캘린더(구글 캘린더와 동기화), 할 일, 습관, 장기 목표. 습관과 할 일을 목표에 연결하면 목표 진행률이 자동 계산됩니다.
리포트주간·월간 요약: 지출, 저축률, 독서량, 공부 시간, 운동 횟수, 수면, 기분, 습관 달성률

리포트와 설정은 폰에서 더보기 탭 안에 있습니다. 설정에는 카테고리 관리, 다크 모드, 전체 데이터 내보내기(백업)가 들어갑니다.

무료로 쓰는 범위

서비스무료 한도알아둘 점
GitHub Pages월 100GB 전송앱 코드가 공개 저장소에 올라갑니다. 기록은 코드에 들어가지 않으므로 공개되지 않습니다.
Supabase 데이터베이스500MB글과 숫자만으로는 수십 년 써도 남습니다. 7일간 접속이 없으면 일시 정지되므로, 매일 자동으로 한 번 접속하는 무료 예약 작업을 함께 만듭니다.
Supabase 사진 저장소1GB사진을 약 200KB로 줄여 올리면 5천 장 정도 들어갑니다. 설정에서 사용량을 보여줍니다.
구글 캘린더 연동무료구글 연결은 약 1시간마다 만료됩니다. 앱이 자동으로 다시 연결하지만, 가끔 구글 버튼을 한 번 더 눌러야 할 수 있습니다.
도서 검색무료검색 결과에 없는 책은 직접 입력할 수 있습니다.

한도는 각 서비스의 현재 무료 요금제 기준이며, 서비스 정책에 따라 바뀔 수 있습니다.

만드는 순서

  1. 뼈대 구글 로그인, 메뉴, 데이터베이스 표 만들기
  2. 기록 화면 8개 영역의 기본 입력과 목록
  3. 홈과 리포트 오늘 요약, 빠른 입력, 통계 그래프
  4. 편의 기능 사진 첨부, 책 검색, 고정 지출 자동 등록, 공부 타이머
  5. 구글 캘린더 동기화
  6. 배포 GitHub Pages에 올리고 폰 홈 화면에 설치
